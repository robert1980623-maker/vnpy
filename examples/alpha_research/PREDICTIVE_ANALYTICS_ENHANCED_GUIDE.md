# 预测分析增强版 - 使用指南

## 功能

每小时自动运行预测分析，包括:

1. 📊 **系统健康度预测** - 基于历史数据预测未来趋势
2. 🔮 **任务成功率预测** - 预测任务执行成功率
3. ⚠️ **异常检测与预警** - 提前发现潜在问题
4. 📈 **趋势分析报告** - 生成自然语言报告
5. 📱 **Slack 自动推送** - 报告发送到 Slack

## 模型

- **模型**: glm-4.7-flash (本地)
- **成本**: ¥0
- **频率**: 每小时一次
- **超时**: 300 秒 (5 分钟)

## 分析内容

### 1. 系统指标收集

- Agent 健康率
- 任务成功率
- 待处理问题数
- Cron 任务数
- 数据新鲜度
- 系统负载

### 2. 预测分析

- 时间序列分析
- 趋势预测
- 异常检测
- 风险评估

### 3. 预警阈值

| 指标 | 警告阈值 | 严重阈值 |
|------|---------|---------|
| Agent 健康率 | < 90% | < 80% |
| 任务成功率 | < 95% | < 90% |
| 待处理问题 | > 5 个 | > 10 个 |
| 数据新鲜度 | < 0.9 | < 0.8 |

## 故障排查

### 问题 1: 超时

**原因**: glm-4.7-flash 模型启动需要时间

**解决**: 确保 timeout >= 300 秒

### 问题 2: 报告未发送

**检查**:
1. cron 任务是否运行
2. delivery 配置是否正确
3. Slack channel ID 是否正确

### 问题 3: 预测不准确

**解决**:
1. 增加历史数据积累
2. 调整预测算法参数
3. 增加数据点数量
