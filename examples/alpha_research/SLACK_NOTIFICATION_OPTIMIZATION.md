# Slack 通知优化方案

## 当前状态分析

### 已配置的通知任务 (34 个)

所有 cron 任务都配置了 delivery，会自动发送到你当前的 Slack channel。

### 通知频率分析

| 频率 | 任务数 | 日均通知数 | 说明 |
|------|--------|-----------|------|
| 每 20 分钟 | 1 个 | 72 条 | QA 变更门禁检查 |
| 每小时 | 8 个 | 192 条 | 健康检查、监控、日志分析等 |
| 每天固定时间 | 25 个 | 25-50 条 | 数据下载、选股、复盘等 |

**总计**: 约 289-314 条通知/天（如果全部发送）

### 问题诊断

❌ **通知过多原因**:
1. 每小时任务太多（8 个 × 24 小时 = 192 条）
2. 每 20 分钟任务（1 个 × 72 次 = 72 条）
3. 正常状态也发送通知（成功/失败都发）

---

## 优化方案

### 方案 1: 只发送异常通知（推荐）

**原则**: 正常不发送，只在失败/异常时通知

| 任务类型 | 当前 | 优化后 | 减少比例 |
|---------|------|--------|---------|
| 每小时监控 | 每次都发 | 仅失败时发 | -95% |
| 健康检查 | 每次都发 | 仅异常时发 | -95% |
| 数据下载 | 每次都发 | 仅失败时发 | -90% |
| 交易任务 | 每次都发 | 仅失败时发 | -80% |
| 每日报告 | 每天都发 | 保持不变 | 0% |

**预期效果**: 289 条/天 → 15-30 条/天

### 方案 2: 合并高频任务

**当前**: 8 个独立的小时任务
```
[10:00] ✅ 每小时监控完成
[10:10] ✅ 数据新鲜度监控完成
[10:15] ✅ Delta 任务消费者完成
[10:20] ✅ 日志分析 Agent 完成
[10:30] ✅ Agent 健康检查完成
[10:40] ✅ Manager 问题队列监控完成
[10:50] ✅ Manager 问题自动处理完成
```

**优化后**: 1 个综合监控任务
```
[11:00] 📊 小时监控摘要
   ✅ 7/7 任务正常
   ⚠️ 0 个警告
   ❌ 0 个失败
```

**预期效果**: 192 条/天 → 24 条/天

### 方案 3: 定时摘要（最适合 Stream 模式）

**保留关键通知** + **定时摘要报告**

| 类型 | 频率 | 内容 |
|------|------|------|
| **立即通知** | 实时 | CRITICAL/HIGH 告警 |
| **晨间简报** | 09:00 | 昨日总结、今日计划 |
| **午间更新** | 12:00 | 上午执行情况 |
| **收盘报告** | 17:30 | 当日交易、盈亏 |
| **晚间复盘** | 20:00 | 完整复盘报告 |

**预期效果**: 289 条/天 → 20-40 条/天

## 推荐配置

### 立即发送（不聚合）

```bash
# CRITICAL 级别 - Agent 崩溃、数据丢失
# HIGH 级别 - 交易失败、风控触发
```

### 聚合发送（每小时汇总）

```bash
# 合并 8 个每小时任务为 1 个摘要
openclaw cron add --name "小时监控摘要" \
  --schedule "5 * * * *" \
  --isolated \
  "python3 -c \"print('📊 小时监控：7/7 正常')\""
```

### 定时摘要（固定时间）

```bash
# 晨间简报
openclaw cron add --name "Slack 晨间简报" \
  --schedule "0 9 * * 1-5" \
  --isolated \
  "python3 slack_digest.py --type morning --non-interactive"

# 午间更新
openclaw cron add --name "Slack 午间更新" \
  --schedule "0 12 * * 1-5" \
  --isolated \
  "python3 slack_digest.py --type noon --non-interactive"

# 收盘报告
openclaw cron add --name "Slack 收盘报告" \
  --schedule "30 17 * * 1-5" \
  --isolated \
  "python3 slack_digest.py --type market_close --non-interactive"

# 晚间复盘
openclaw cron add --name "Slack 晚间复盘" \
  --schedule "0 20 * * 1-5" \
  --isolated \
  "python3 slack_digest.py --type evening --non-interactive"
```
