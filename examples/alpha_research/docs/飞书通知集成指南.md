# 📱 飞书通知集成指南

## 概述

本系统支持将量化交易任务的通知自动发送到飞书群，包括：
- ✅ 数据下载任务
- ✅ 每日选股任务
- ✅ 交易执行任务
- ✅ 每日复盘任务
- ✅ 合规检查任务
- ✅ 数据质量监控

## 配置说明

### 1. 配置文件

位置：`config/feishu_notification_config.json`

```json
{
  "chat_id": "oc_21ccc3d7355ceabbdfb1e027af5441e5",  // 飞书群 ID
  "account_id": "default",  // OpenClaw 账户 ID
  "enabled": true,  // 是否启用通知
  "tasks": {
    "每日选股": {
      "notify_on": ["start", "complete", "error"],  // 通知时机
      "emoji": "🎯",
      "priority": "high"
    }
  }
}
```

### 2. 支持的通知时机

| 时机 | 说明 | 适用场景 |
|------|------|---------|
| `start` | 任务开始时 | 耗时较长的任务 |
| `complete` | 任务完成时 | 所有任务 |
| `error` | 任务失败时 | 所有任务 |
| `warning` | 任务警告时 | 监控类任务 |

## 使用方法

### 方法 1: 直接导入使用

```python
from feishu_notifier import FeishuNotifier

# 创建通知器
notifier = FeishuNotifier()

# 发送任务开始通知
notifier.notify_start(
    "每日选股",
    details={"日期": "2026-03-19", "模式": "自动"}
)

# 发送任务完成通知
notifier.notify_complete(
    "每日选股",
    content="✅ 成功筛选出 15 只符合策略的股票",
    details={
        "候选股票数": "150",
        "入选股票数": "15",
        "通过率": "10%"
    }
)

# 发送任务错误通知
notifier.notify_error(
    "数据下载",
    error_msg="网络超时，无法连接数据源",
    details={"数据源": "Tushare", "重试次数": "3"}
)
```

### 方法 2: 使用便捷函数

```python
from feishu_notifier import notify_task_start, notify_task_complete, notify_task_error

# 任务开始
notify_task_start("每日选股", 日期="2026-03-19")

# 任务完成
notify_task_complete("每日选股", content="筛选完成", 入选股票数=15)

# 任务错误
notify_task_error("数据下载", error_msg="网络错误")
```

### 方法 3: 在 cron 脚本中集成

```python
#!/usr/bin/env python3
"""每日选股脚本 - 带飞书通知"""

import sys
from pathlib import Path
sys.path.insert(0, str(Path(__file__).parent))

from feishu_notifier import FeishuNotifier
from daily_stock_selection import run_stock_selection

def main():
    notifier = FeishuNotifier()
    
    try:
        # 发送开始通知
        notifier.notify_start("每日选股")
        
        # 执行选股
        result = run_stock_selection()
        
        # 发送完成通知
        notifier.notify_complete(
            "每日选股",
            content=f"✅ 成功筛选出 {result['count']} 只股票",
            details=result
        )
        
    except Exception as e:
        # 发送错误通知
        notifier.notify_error("每日选股", str(e))
        raise

if __name__ == "__main__":
    main()
```

## 故障排查

### 通知未发送

1. 检查 `config/feishu_notification_config.json` 中 `enabled` 是否为 `true`
2. 检查 `chat_id` 是否正确
3. 检查 OpenClaw 是否正常运行：`openclaw status`
4. 查看日志文件：`logs/feishu_notifications.log`

### 消息格式错误

确保消息内容不包含飞书不支持的 Markdown 语法。

### 发送失败

查看错误输出，常见问题：
- OpenClaw 未运行 → `openclaw gateway start`
- 账户未授权 → `openclaw feishu-auth`
- 群权限不足 → 检查机器人是否在群内

## 最佳实践

1. **重要任务开启 start 通知**：让用户知道任务已开始执行
2. **错误通知必须开启**：及时发现问题
3. **合理设置优先级**：避免通知过多造成骚扰
4. **提供详细信息**：在 details 中包含关键指标
5. **定期检查日志**：确保通知系统正常工作
