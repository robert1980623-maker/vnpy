## 使用方法

### 方法 1: 直接传入股票列表

```python
from feishu_notifier import FeishuNotifier

notifier = FeishuNotifier()

# 选股完成后发送详细通知
notifier.notify_complete(
    "每日选股",

    details={

        "入选股票数": "5",
        "通过率": "3.3%"
    },
    stocks=selected_stocks,  # 股票列表
    top_n=10  # 显示前 10 只
)
```

### 方法 2: 在 daily_stock_selection.py 中集成

```python
#!/usr/bin/env python3
"""每日选股脚本 - 带详细飞书通知"""

from feishu_notifier import FeishuNotifier
from pathlib import Path
import json

def main():
    notifier = FeishuNotifier()
    
    try:
        # 1. 发送开始通知
        notifier.notify_start("每日选股")
        
        # 2. 执行选股
        selector = DailyStockSelector()
        selected_stocks = selector.run()
        
        # 3. 保存选股报告
        report_path = save_stock_selection_report(selected_stocks)
        
        # 4. 发送完成通知（包含详细股票列表）
        notifier.notify_complete(
            "每日选股",
            content=f"✅ 多策略选股完成，共筛选出 {len(selected_stocks)} 只优质股票",
            details={
                "候选股票数": str(selector.total_count),
                "入选股票数": str(len(selected_stocks)),
                "通过率": f"{len(selected_stocks)/selector.total_count*100:.1f}%",
                "报告文件": str(report_path)
            },
            stocks=selected_stocks,  # 关键：传入股票列表
            top_n=10  # 显示前 10 只
        )
        
    except Exception as e:
        # 5. 错误通知
        notifier.notify_error("每日选股", str(e))
        raise

if __name__ == "__main__":
    main()
```

## 通知内容说明

### 1. 策略标签

自动根据选股策略显示标签：
- `[价值]` - 价值投资策略
- `[成长]` - 成长股策略
- `[质量]` - 高质量策略
- `[高息]` - 高股息策略

### 2. 入选原因

显示每条策略的具体原因：
- 价值股：`PE=20.3, ROE=25.1%, 股息率=1.5%`
- 成长股：`营收增长=79.8%, 利润增长=273.5%`
- 质量股：`ROE=25.9%`
- 高息股：`股息率=3.5%`

### 3. 关键指标

自动汇总显示关键财务指标：
- PE（市盈率）
- ROE（净资产收益率）
- 营收增长率
- 利润增长率
- 股息率

### 4. 评分排序

股票按评分从高到低排序，评分计算规则：
- 每满足 1 个策略：+2 分
- 满足≥3 个策略：+1 分
- 满足 4 个策略：+1 分

## 配置选项

在 `config/feishu_notification_config.json` 中配置：

```json
{
  "每日选股": {
    "notify_on": ["start", "complete", "error"],
    "emoji": "🎯",
    "priority": "high"
  }
}
```

### top_n 参数

控制显示的股票数量：
- `top_n=5`：显示前 5 只
- `top_n=10`：显示前 10 只（默认）
- `top_n=20`：显示前 20 只

如果选股数量超过 `top_n`，会显示提示：
```
💡 还有 5 只股票，详见报告文件
```

## 常见问题

### Q: 股票名称显示为"未知"？
A: 确保股票数据中包含 `name` 字段，可以从 `stock_name_utils.py` 获取。

### Q: 消息太长被截断？
A: 减小 `top_n` 参数，或精简 `reasons` 内容。

### Q: 如何自定义显示格式？
A: 修改 `_format_stocks_message()` 方法。
