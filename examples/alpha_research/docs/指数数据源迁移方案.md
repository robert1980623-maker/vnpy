#### 2.4 更新 `cache_meta.json`

**操作**: 清理旧版指数元数据记录

```python
import json

# 读取元数据
with open('cache/fundamental/cache_meta.json', 'r') as f:
    meta = json.load(f)

# 识别旧版 key
old_keys = [k for k in meta.keys() if k.startswith('SH000001_') or k.startswith('SZ399001_') or k.startswith('US_DJIA_')]

# 删除旧版记录（可选，建议先保留）
for key in old_keys:
    del meta[key]

# 保存
with open('cache/fundamental/cache_meta.json', 'w') as f:
    json.dump(meta, f, indent=2, ensure_ascii=False)
```
