# VNPY 项目概览

## 项目定位

基于 Vnpy 框架的**智能量化交易系统**，融合 AI Agent 自动化能力。

## 核心模块

### 1. Alpha 研究系统
- **股票池管理** - 指数成分股、自定义股票池
- **财务数据** - 5 大类财务指标管理
- **选股策略** - 价值/成长/质量/高股息策略
- **截面回测引擎** - 多股票回测与绩效分析

### 2. AI Agent 系统
- **Delta Consumer** - 自动修复代码错误（每 5 分钟）
- **Manager** - 问题队列分析与调度（每 30 分钟）
- **QA Architect** - 测试生成与质量检查
- **System Architect** - 架构审查与优化
- **Data Agent** - 数据下载与验证
- **Log Analyzer** - 日志分析与异常检测
- **Chief Risk Officer** - 风险监控

### 3. 交易执行系统
- **虚拟账户** - 模拟交易与仓位管理
- **实时监控** - 每小时市场监控
- **每日选股** - 09:00 自动选股
- **每日交易** - 09:35 虚拟交易执行
- **每日复盘** - 20:00 交易复盘

### 4. 数据系统
- **多数据源** - AKShare, Tushare, Baostock, RQData
- **数据新鲜度监控** - 自动检测数据过期
- **增量下载** - 优化下载效率
- **数据验证** - 质量检查与异常处理

### 5. 任务调度系统
- **Cron 任务** - 定时任务管理
- **任务监控** - 09:00/17:00 状态检查
- **问题闭环** - 错误检测 → 分析 → 修复 → 验证

### 6. 报告与通知
- **每日报告** - 交易总结与绩效分析
- **每小时报告** - 市场状态更新
- **飞书通知** - 实时告警与摘要
- **Slack 集成** - 监控流推送
