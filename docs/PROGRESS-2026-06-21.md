## 🏗️ 架构变更

### 1. 统一 CLI 系统

**位置**: `cli/` 目录

**结构**:
```
cli/
├── main.py              # 统一入口
├── commands/
│   ├── download.py      # 数据下载
│   ├── trade.py         # 交易执行
│   ├── report.py        # 报告生成
│   ├── health.py        # 健康检查
│   └── cron.py          # Cron 管理
└── utils/
    ├── config.py        # 配置加载
    ├── logging.py       # 结构化日志
    ├── errors.py        # 错误处理
    ├── wrapper.py       # 旧脚本桥接
    └── cron_schema.py   # Cron 配置校验
```

**使用方式**:
```bash
vnpy download akshare --validate --max 50
vnpy trade execute --strategy daily_rotation
vnpy report generate --type performance
vnpy health check
vnpy cron list
```

### 2. 数据校验管道

**位置**: `examples/alpha_research/data_validator.py`

**功能**:
- 行数校验（>= 200 行/年）
- 日期连续性（检查交易日缺失）
- 数值范围（股价 > 0，成交量 >= 0）
- 字段完整性（date/open/high/low/close/volume）
- 数据新鲜度（最新日期 <= 今天 - 1 天）

**集成**:
```bash
vnpy download akshare --validate  # 下载后自动校验
```

### 3. CI/CD 流水线

**位置**: `.github/workflows/ci.yml`

**Jobs**:
- `lint`: ruff 代码检查
- `typecheck`: mypy 类型检查（非阻塞）
- `test`: pytest 测试矩阵（Python 3.11-3.14）
- `build`: 打包验证
- `integration`: 集成测试（可选，需 secrets）

**触发条件**:
- Push to main/master
- Pull request to main/master
- 手动触发（workflow_dispatch）

### 4. 异步优化

**位置**: `examples/alpha_research/data_downloader.py`

**改进**:
- 新增 `AsyncRateLimiter`（asyncio.Lock + asyncio.sleep）
- 新增 `_download_one_async()`（asyncio.to_thread 包装）
- 新增 `download_batch_async()`（asyncio.gather 全并发）
- 保持同步 API 向后兼容

### 5. 日志系统统一

**范围**: 20 个核心模块

**改进**:
- 替换 923 个 `print()` 为 `logger` 调用
- 统一日志格式（JSON + trace_id）
- 支持结构化日志查询
