# 精英组合系统使用指南

**版本**: v1.0  
**更新日期**: 2026-03-12  
**目标**: 精选 5 只股票 + 严格止盈止损 + 实时监控 + 消息面整合

---

## 🎯 核心特性

### 1. 精选 5 只股票
- 从全市场筛选，宁缺毋滥
- 综合评分 = 基本面 40% + 消息面 25% + 时政面 20% + 国际形势 15%
- 评分阈值：≥70 分（可降至≥65 分）

### 2. 严格止盈止损
- **止损**: -15% 强制卖出
- **止盈**: +30% 建议卖出（可分批）
- **预警**: -10% 提醒关注

### 3. 消息面整合
- 政策影响（宏观 + 行业）
- 国际形势（中美关系 + 地缘政治）
- 个股新闻（公告 + 资金流向）

### 4. 每小时实时监控
- 更新持仓价格
- 检查止盈止损
- 检查仓位比例
- 发送告警通知

## 🚀 快速启动

### 步骤 1: 精选选股（每日 09:00）

```bash
cd /Users/rowang/projects/vnpy/examples/alpha_research
source /Users/rowang/projects/vnpy/venv/bin/activate
python3 elite_stock_selector.py
```

**输出**:
- `reports/elite_selection_YYYY-MM-DD.json` - 精选 5 只股票报告

### 步骤 2: 止盈止损检查（实时）

```bash
python3 strict_stop_loss.py
```

**功能**:
- 自动卖出亏损超 15% 的股票
- 建议止盈盈利超 30% 的股票
- 预警亏损超 10% 的股票

### 步骤 3: 持仓重组（调仓至 5 只）

```bash
python3 rebalance_portfolio.py
```

**功能**:
- 清理当前 38 只持仓
- 调仓至精选 5 只
- 控制单只仓位≤15%
- 保留 5-10% 现金

### 步骤 4: 设置实时监控（每小时）

```bash
# 手动执行一次
python3 realtime_monitor.py --once

# 或持续监控（每小时）
python3 realtime_monitor.py --interval 3600

# 或配置定时任务
python3 setup_elite_cron.py
```

## ⏰ 定时任务配置

运行 `setup_elite_cron.py` 自动配置以下任务：

| 任务 | 时间 | 频率 | 说明 |
|------|------|------|------|
| 数据更新 (凌晨) | 01:00 | 每日 | 下载最新数据 |

| 精选选股 | 09:00 | 周一 - 五 | 精选 Top 5 |
| 数据更新 (下午) | 17:00 | 每日 | 下载收盘数据 |
| 每日调仓 | 17:30 | 周一 - 五 | 调仓至 5 只 |
| 止盈止损检查 | 15:00 | 周一 - 五 | 收盘后检查 |
| 每日复盘 | 20:00 | 周一 - 五 | 生成复盘报告 |

## 📊 选股标准

### 基本面筛选（初筛）

至少满足 2 个策略：

| 策略 | 条件 | 权重 |
|------|------|------|
| 价值股 | PE<20, ROE>10%, 股息率>2% | 基础分 |
| 成长股 | 营收增长>25%, 利润增长>30% | 基础分 |
| 质量股 | ROE>15% | 基础分 |
| 高息股 | 股息率>3% | 基础分 |

### 综合评分（精选）

| 维度 | 权重 | 说明 |
|------|------|------|
| 基本面 | 40% | PE、ROE、增长等 |
| 消息面 | 25% | 政策、新闻、公告 |
| 时政面 | 20% | 宏观政策、行业政策 |
| 国际形势 | 15% | 中美关系、地缘政治 |

**入选阈值**: ≥70 分（宁缺毋滥）

## 💡 使用建议

### 每日流程

```
09:00 → 运行 elite_stock_selector.py（精选选股）
  ↓
15:00 → strict_stop_loss.py（止盈止损检查）
  ↓
17:00 → download_data_akshare.py（更新数据）
  ↓
17:30 → rebalance_portfolio.py（执行调仓）
  ↓
20:00 → daily_review.py（每日复盘）
```

### 每小时监控

```
整点 → realtime_monitor.py
  ↓
- 更新持仓价格
- 检查止盈止损
- 检查仓位比例
- 发送告警通知
```

### 注意事项

1. **数据新鲜度**: 确保每日 17:00 更新数据
2. **止盈止损**: 严格执行，避免深度套牢
3. **仓位控制**: 单只不超过 15%，保留 5-10% 现金
4. **消息面**: 关注政策变化和国际形势

## 📞 故障排查

### 常见问题

**Q: 选股结果为 0 只？**
A: 降低阈值（修改 `elite_stock_selector.py` 中的 `final_score >= 70` 改为 `>= 65`）

**Q: 实时监控不发送告警？**
A: 检查 `DINGTALK_WEBHOOK` 环境变量是否配置

**Q: 调仓失败？**
A: 检查现金是否充足，或手动执行卖出释放资金

**Q: 数据滞后？**
A: 运行 `python3 download_data_akshare.py --end $(date +%Y-%m-%d)` 更新数据
